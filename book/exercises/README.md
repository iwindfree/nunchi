# 연습문제

## 푸는 방법

```bash
cd book/exercises
cargo test -p ex_00_02_a       # 한 문제만 확인합니다
cargo test                     # 전체를 확인합니다
```

각 문제는 `src/lib.rs`에 `TODO` 주석이 있습니다. 그 부분을 고쳐서 테스트가
통과하게 만들면 됩니다. 처음에는 컴파일조차 되지 않는 문제도 있습니다.
그것이 정상입니다.

## 정답

`solutions/` 디렉터리에 있습니다.

**정답을 먼저 보시면 배우는 것이 거의 없습니다.** Rust 컴파일러의 오류
메시지는 다른 언어와 비교해 매우 자세합니다. 오류 메시지를 세 번 읽어 보시고,
그래도 막히면 그때 여십시오. 컴파일러가 알려 주는 내용을 읽는 습관이
Rust를 배우는 가장 빠른 방법입니다.

정답을 확인하는 방법은 다음과 같습니다.

```bash
cat solutions/ex_00_02_a.rs
```

## 문제 번호 규칙

`ex_<부>_<장>_<순번>` 형식입니다. `ex_01_04_b`는 1부 4장의 두 번째 문제를
뜻합니다. 문서의 해당 장에서 문제 설명을 볼 수 있습니다.
