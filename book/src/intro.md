# 시작하기 전에

이 책은 두 권으로 나뉘어 있습니다.

**1권은 Rust 문법**을 다룹니다. Rust를 처음 접하는 사람도 읽을 수 있게 썼습니다.
다른 프로그래밍 언어 경험은 있다고 가정하지만, Rust 지식은 전혀 없다고
가정합니다.

**2권은 nunchi 코드**를 설명합니다. 실행되는 순서를 따라가면서 코드를 한 줄씩
읽습니다.

## 책을 보는 방법

이 책은 mdBook으로 만들었습니다.

```bash
cargo install mdbook
cd book && mdbook serve --open
```

브라우저가 열리고 사이드바 목차와 전문 검색을 쓸 수 있습니다.

다이어그램은 mermaid로 그렸는데, 별도 도구가 필요하지 않습니다. 브라우저에서
그리도록 만들어 두었기 때문입니다. GitHub에서 파일을 직접 읽으셔도 그림이
보입니다. GitHub이 mermaid를 자체적으로 그려 주기 때문입니다. 다만 그 경우
검색과 목차는 쓸 수 없습니다.

## 읽는 순서

두 가지 방법이 있습니다.

**차례대로 읽는 방법**을 권합니다. 1권 0부와 1부를 먼저 읽으시면 됩니다.
소유권을 이해하지 못한 상태에서 Rust 코드를 읽으면 대부분의 줄에서 막힙니다.
1부까지 읽고 나면 2권을 읽기 시작하셔도 됩니다.

**필요할 때 찾아보는 방법**도 가능합니다. 2권의 각 장 맨 위에 그 장을 읽는 데
필요한 문법 장이 적혀 있습니다. 모르는 문법이 나오면 그때 링크를 따라가시면
됩니다. 다만 1부 소유권은 미리 읽어 두시는 편이 낫습니다.

## 이 책의 특징

**모든 예시가 nunchi의 실제 코드입니다.** 일반적인 Rust 교재는 낯선 예제로
문법을 설명하므로, 예제를 이해한 다음 다시 우리 코드에 대응시키는 두 단계를
거쳐야 합니다. 이 책은 그 단계를 없앴습니다.

**선행 관계를 지킵니다.** A를 설명하는 데 B가 필요하면 B가 반드시 먼저
나옵니다. 예를 들어 `?` 연산자는 이 코드에 319번 나오는 가장 흔한 문법이지만,
2부 3장에 있습니다. `?`를 이해하려면 `Result`를 알아야 하고, `Result`를 알려면
열거형과 타입 표기를 읽을 수 있어야 하기 때문입니다.

이 규칙은 스크립트로 검사합니다. 어떤 장이 자기보다 뒤에 오는 장을 선행으로
지정하면 검사에서 오류가 납니다.

## 연습문제

문법 장에는 연습문제가 있습니다. 세 종류입니다.

| 표시 | 방식 |
|---|---|
| 읽기 | 코드를 보고 무엇을 하는지 답합니다. 정답은 접힌 블록에 있습니다 |
| 고치기 | 컴파일 오류를 고칩니다. `cargo test`가 통과하면 정답입니다 |
| 쓰기 | 테스트를 통과하는 코드를 작성합니다 |

푸는 방법은 다음과 같습니다.

```bash
cd book/exercises
cargo test -p ex_00_02_a
```

정답은 `book/exercises/solutions/`에 있습니다. 다만 **정답을 먼저 보시면
배우는 것이 거의 없습니다.** Rust 컴파일러의 오류 메시지는 다른 언어와 비교해
매우 자세하며, 대부분 무엇을 고쳐야 하는지까지 알려 줍니다. 오류 메시지를
세 번 읽어 보시고 그래도 막히면 그때 여십시오.

## 이 코드베이스가 Rust 학습에 유리한 이유

nunchi의 Rust 코드를 실제로 세어 보았습니다.

| 문법 요소 | 횟수 |
|---|---|
| `?` 연산자 | 319 |
| 클로저 | 262 |
| `.clone()` | 170 |
| 수명 표기 `<'a>` | **6** |
| 트레이트 정의 | **1** |
| `macro_rules!` | **1** |
| 제네릭 함수 | **0** |
| `dyn`, `Box<dyn>`, `RefCell` | **0** |

초보자를 가장 괴롭히는 요소들이 마침 거의 없습니다. 수명 표기가 여섯 번,
트레이트 정의가 하나, 매크로가 하나이며 동적 디스패치는 아예 없습니다.

**실제 어려움은 다른 곳에 있습니다.** `?` 연산자와 이터레이터 체인이 코드의
골격이고, `.clone()`이 170번 나오는 이유를 이해하려면 소유권을 알아야 합니다.
그래서 이 책은 소유권에 여섯 장을, 이터레이터에 세 장을 씁니다.

## 사용하는 Rust 버전

이 프로젝트는 **edition 2024**를 사용하며 Rust 1.90 이상이 필요합니다.
edition은 Rust가 하위 호환을 유지하면서 문법을 바꾸는 장치입니다. 2015, 2018,
2021, 2024가 있고 2024가 최신입니다.

책의 모든 설명은 edition 2024를 기준으로 합니다.
